# Ticora — Tic-Tac-Toe

Ticora is a simple, interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript. Players take turns marking X and O on a 3×3 grid, with automatic winner and draw detection.

**Tech Stack:** HTML · CSS · JavaScript

**Key Features**
- Interactive 3×3 game board
- Alternating turns between X and O
- Automatic winner detection
- Draw detection
- Reset and replay functionality *(if implemented)*

**Learning Goals:** DOM manipulation, event handling, conditional logic, and JavaScript functions.
